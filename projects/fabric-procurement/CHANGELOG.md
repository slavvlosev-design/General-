# Изменения

## 1.1 — 12.10.2026

- Подтверждён коэффициент микро 3,2 м/кг и применение кратности к общему заказу цвета, с делением между контейнерами.
- Зафиксирован мартовский сценарий: прежние исходники, производство с нуля, нулевой доступный остаток, принятая часть и отдельные исключения.
- Подготовлен локальный заказ в форме поставщика; коммерческие данные и цены в GitHub не публикуются.
- Добавлены приёмочные примеры для деления партий и отсутствующих цен/партий.

## 1.0 — 09.10.2026

- Собрана основа проекта из переписки, проверенных входов и ограничений предварительного расчёта.
- Зафиксированы бизнес-цель, периоды, нормы, две надбавки, партии, единицы, сроки и датированный баланс.
- Добавлены архитектура Python 3.13, контракты данных, статусы, безопасность, воспроизводимость и критерии приёмки.
- Разделены подтверждённые правила, проектные решения, исторический прототип и открытые вопросы.
- Принято размещение документации в публичной папке GitHub; коммерческие входы и расчёт оставлены локально по решению заказчика.
