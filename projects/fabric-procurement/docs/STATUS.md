Дата: 09.10.2026. Это состояние материалов, а не заявление о готовой программе.

- Изучены план продаж, ресурсные спецификации, таблица партий и схема Holst.
- Согласованы периоды, кабинет, продажи в штуках, две надбавки и кратность цвета.

## Что не сделано

Нет полной потребности по всем изделиям, чистого заказа с вычетом склада, проверенного календаря контейнеров, прямого API 1С, готового приложения на Python 3.13 или автоматической отправки поставщику.

## План работ

| Этап | Работа | Критерий выхода |
|---|---|---|
| M0 Данные | Закрыть Q01–Q07: связи, повторы, нормы, материалы, партии | Полный проверенный набор либо согласованный частичный охват |
| M1 Ядро потребности | Реализация Python 3.13, импорт, валидация, календарь, нормы и надбавки | Воспроизводимый отчёт, тесты T01–T17, T25–T34 по применимости |
| M2 Обеспечение | ГП/НЗП, склад, резервы, поставки, даты потребления | Подтверждённый баланс без двойного учёта |
| M3 Проект заказа | Кратность, перенос остатков, сценарии сроков | Партии и дефициты по датам проверены |
| M4 Контейнеры | Вместимость, календарь, состав, исключения | Выполнимый план поставок либо точный список нарушений |
| M5 Эксплуатация | Адаптер 1С, права, расписания, утверждение, мониторинг | Назначены владельцы, проверены восстановление и повторный запуск |

Сроки реализации не оценены: объём интеграции и исправлений исходных данных пока неизвестен. На каждом этапе согласуется конкретный критерий готовности, а не только демонстрация интерфейса.

## Передача следующему разработчику

1. Прочитать DESIGN, DECISIONS и DATA_CONTRACTS.
2. Получить локальные коммерческие исходники у владельца и сверить SHA-256.
3. Не принимать кандидатов артикулов за подтверждённые связи.
4. Не использовать исторический Excel как эталон полноты; использовать его для трассировки и сверки рассчитанной части.
5. Начать с M0/M1, а не с автоматической отправки заказа.
